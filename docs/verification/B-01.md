  empty database, fake workout model or feature navigation scaffolding.
- Static dependency guards currently reserve empty data/domain boundaries. They enforce
  import direction when real code arrives, not the correctness of unimplemented rules.
  Core rule tests and Room/schema tests must accompany their authorised stories.
- No release signing key, credentials, SDK paths or personal data in source. Debug uses
  a separate application ID. No binaries uploaded; release key custody/update policy
  documented before future personal-use distribution.
- Local Android 17 emulator boot attempt did not reach an ADB-ready state; stopped only
  the emulator started for this task. Broader API 33/37 matrix remains a release gate.
- No full T-01 workout, persistence/recovery/migration or 10,000-set NFR-05 result is
  claimed. These need later stories; the initial debug proxy is not final qualification.
- Additional light/200%-font/landscape screenshots captured the phone's charging lock

  and rotation settings were restored. The normal-size dark and offline screens were
  inspected successfully earlier. Full TalkBack/font/rotation checks remain T-14 work.

  later real-data/device testing. Manifest backup exclusions are present now.
- No product or architectural decision requires reopening. PR is not merged; Issue #7
