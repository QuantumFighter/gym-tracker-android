# Refine program/library forms and history/progress navigation

This is a refinement umbrella, not one large implementation story. Split into independently reviewable increments after the gap audit. Related B-11, B-12, B-13; existing B-05 history and B-10 estimates.

Candidate slices:
1. Programs/create/edit/switch and preservation of active-session identity.
2. Routine editor, prescription settings, custom exercise and multi-select library picker.
3. Summary/history with exact snapshots; Progress graphs with defined comparable metrics.
4. Auto progression label/access and evidence explanation under current approved rules.

Each child issue must link its screenshot, specify real data source and failure behaviour, resolve requirement/test IDs, preserve immutable history, pass applicable CI and obtain native visual approval. User-approved layout does not authorise demo validation bounds or missing recording types. Generator setup is separate M3 scope, requiring session-length reconciliation and a real editable draft.
