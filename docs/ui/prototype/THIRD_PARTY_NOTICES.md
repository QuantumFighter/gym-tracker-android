# Third-party assets

Barlow regular and medium: Google Fonts distribution, upstream Barlow by Jeremy Tribby and contributors. SIL Open Font License 1.1; see assets/BARLOW-OFL.txt. Font bytes fetched from fonts.gstatic.com/s/barlow/v13 on 2 November 2026. The bundled font faces are embedded into the source so opening the preview needs no network.

Lucide 1.8.0: installed runtime distribution, ISC license with retained upstream notices; see assets/LUCIDE-LICENSE.txt. The UMD library is embedded in the source. Icons are loaded before screen scripts for standalone use.

The original standalone index was rendered using the available visualization export utility, then its unused remote script requests were removed. Browser preview scaffolding is not Android production code. The included rebuild.py can create a minimal host-independent HTML document from the same source without requiring the visualization utility.
